# PDF Knowledge Extraction System using Hybrid RAG-CAG and LLM

## Overview

This project is an AI-powered document question-answering system that enables users to upload PDF files and interact with them through a chatbot.

The system uses:

- RAG (Retrieval-Augmented Generation)
- CAG (Cache-Augmented Generation)
- Gemini LLM
- ChromaDB Vector Database
- Sentence Transformers Embeddings

## Features

- PDF Upload and Processing
- Text Extraction
- Intelligent Chunking
- Embedding Generation
- ChromaDB Storage
- Semantic Search
- Gemini AI Integration
- Interactive Chatbot
- Response Caching
- Accurate Question Answering

## Technology Stack

- Python
- Jupyter Notebook
- ChromaDB
- Sentence Transformers
- Google Gemini API
- LangChain
- PyPDF

## Workflow

PDF → Text Extraction → Chunking → Embeddings → ChromaDB → RAG Retrieval → Gemini LLM → CAG Cache → User Response

## Applications

- Research Paper Analysis
- Resume Screening
- Educational Documents
- Knowledge Management
- Enterprise Document Search
